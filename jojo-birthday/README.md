# عيد ميلاد جوجو 🎂

## التشغيل
```bash
npm install
npm run dev
```
افتحي اللينك اللي هيظهر (غالبًا http://localhost:5173).

## التعديل
كل حاجة في `src/config.js`: الاسم، الباسورد، الأمنية، ورسالتك.

## النشر
```bash
npm run build
```
ارفعي فولدر `dist` على https://app.netlify.com/drop وهياخد لينك على طول.
